# StampCut — быстрый видеоредактор и плеер для редакции Telegram-каналов

Маленькое приложение под Windows 11 для коротких роликов с разных телефонов: открыл, посмотрел,
обрезал, склеил, наложил логотип, замазал лицо, запикал слово, нажал «Экспорт» — и получил MP4,
который Telegram и соцсети играют без пережатия. Все технические решения (кодеки, GPU, HDR,
частота кадров, размер, качество, имена файлов) приложение принимает само.

Прототип по духу — [Machete](https://www.machetesoft.com/about-machete.html): одно окно, ничего лишнего.

## Возможности

- **Плеер**: двойной клик по видео в проводнике (или `StampCut.exe файл.mp4`) — открывается и сразу играет. HEVC/HDR с iPhone, повёрнутые и не-MP4 файлы получают прокси для просмотра автоматически.
- **Обрезка** точками входа/выхода (`I` / `O`), покадрово (`←` `→`).
- **Склейка** нескольких роликов по порядку; у каждого своя обрезка, кроп и ретушь.
- **Оверлей** PNG с прозрачностью: до трёх штук, перетаскивание и растягивание на превью, 9 якорей, прозрачность, интервал показа, плавное появление. Пресеты и общая библиотека редакции.
- **Кроп** с фиксированными пропорциями (9:16, 1:1, 4:5, 16:9…), «применить ко всем».
- **Ретушь**: размытие или мозаика на лица, номера, недопустимый контент; интервал показа.
- **Запикать**: фрагмент звука тоном 1 кГц или тишиной.
- **Экспорт в один клик** с автоматическим именем файла и папкой; авто-качество (CRF 18 + потолок битрейта по исходнику), размер и частота кадров исходника без увеличения, H.264 High + AAC в MP4 с `faststart` — максимально совместимый формат для Telegram.
- **GPU**: NVENC / Intel Quick Sync / AMD AMF и аппаратное декодирование — автоматически, с проверкой и откатом на CPU.
- **Без перекодирования**: режим Machete для обрезки и склейки совместимых файлов за секунды.
- Недавние файлы и папки, горячие клавиши, журнал и кнопка «Скопировать команду ffmpeg» для разбора проблем.
- `stampcut-cli.exe` — то же самое из командной строки.

## Скачать и установить

Сборка под Windows делается автоматически в GitHub Actions на каждый push в `main`
(вкладка **Actions** → последний запуск **build** → раздел **Artifacts** → `StampCut-win-x64`).
Внутри два варианта:

- `StampCut-Setup-<версия>.exe` — установщик: ярлыки, пункт «Открыть с помощью» для видео, по желанию — StampCut как программа по умолчанию для MP4/MOV/MKV.
- `StampCut-portable-win-x64.zip` — распаковать куда угодно и запустить `StampCut.exe`.

FFmpeg (сборка BtbN win64-gpl) уже внутри. Установщик не подписан: SmartScreen при первом запуске
покажет предупреждение, нажмите «Подробнее» → «Выполнить в любом случае».

Релиз с готовыми файлами публикуется при пуше тега `v*`.

## Как пользоваться

1. Перетащите видео в окно (или откройте через «Открыть…», «Недавние»). Для склейки добавьте ещё роликов кнопкой «+ Добавить ролик».
2. Ролик сразу играет. `Пробел` — пауза, `I` / `O` — точки входа и выхода, `Home` / `End` — к ним.
3. Справа: **Оверлей** (выберите пресет или PNG, подвиньте мышью), **Кроп**, **Ретушь** («+ Размытие», область можно таскать), **Запикать звук**.
4. Выберите пресет экспорта («Telegram 1080p» подходит почти всегда) и нажмите **Экспорт** (`Ctrl+E`). Файл появится рядом с исходником с суффиксом `_tg`, кнопки «Показать в проводнике» — в полосе уведомления.

Чтобы Telegram не пережимал видео, отправляйте с **Telegram Desktop** или «как файл»: мобильные клиенты
пережимают всё, что отправлено «как видео», независимо от формата.

**Общая библиотека редакции.** В «Настройках» укажите папку (сетевую или в облаке) с подпапками `overlays/`
(PNG) и `presets/export`, `presets/overlay` (JSON, примеры в `presets-examples/`) — у всех сотрудников будут
одинаковые оверлеи и пресеты. Кнопка «По умолчанию» в панели оверлея делает пресет автоматическим для всех новых проектов.

## Командная строка

`stampcut-cli.exe` рядом с приложением — те же возможности для скриптов и проверки конвейера
(графическое приложение — `StampCut.exe`, ему можно передать файл аргументом):

```bash
stampcut-cli probe IMG_1234.MOV
```

```bash
stampcut-cli export --preset telegram-1080p --overlay logo.png --anchor bottom-right --size 25 --opacity 0.8 --clip IMG_1234.MOV --in 2 --to 45 --blur 0.4,0.3,0.2,0.3 --beep 10-11.5
```

`stampcut-cli export --list-presets` покажет пресеты, `--dry-run` напечатает команду ffmpeg без запуска,
`stampcut-cli detect` — что из GPU реально работает и почему нет.

## Сборка из исходников

Нужен .NET 8 SDK. Ядро и CLI собираются и тестируются на любой ОС, приложение WPF — компилируется везде, запускается на Windows.

```bash
dotnet build -c Release
```

```bash
dotnet test tests/StampCut.Core.Tests -c Release
```

```bash
dotnet publish src/StampCut.App -c Release -r win-x64 --self-contained true -p:PublishSingleFile=true -o dist/StampCut
```

После этого положите `ffmpeg.exe` и `ffprobe.exe` в `dist/StampCut/tools/ffmpeg/` (см. `tools/ffmpeg/README.md`).

## Лицензии

Лицензия StampCut не выбрана (открытый вопрос в ТЗ). FFmpeg распространяется под GPL; приложение вызывает
`ffmpeg.exe` как отдельный процесс, текст лицензии FFmpeg кладётся в `tools/ffmpeg/`.
