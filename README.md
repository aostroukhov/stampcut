# StampCut — быстрый видеоредактор для редакции Telegram-каналов

**StampCut** (рабочее название) — маленькое и быстрое приложение под Windows 11 для
коротких роликов (до 5 минут), снятых на разные телефоны. Задачи:

1. открыть видео с любого телефона и сразу его увидеть;
2. обрезать начало и конец;
3. наложить оверлей редакции — PNG с прозрачностью, с выбором положения, размера и прозрачности;
4. экспортировать MP4, который Telegram и другие соцсети играют без сюрпризов.

Прототип по духу — [Machete](https://www.machetesoft.com/about-machete.html): одно окно,
никаких дорожек и эффектов, ничего лишнего.

## Как вынести в отдельный репозиторий

Проект лежит в папке `stampcut/` репозитория `charPicker`, потому что из сессии, в которой
он создан, нельзя было создать новый репозиторий. Чтобы перенести его в свой репозиторий
с сохранением истории:

```bash
git subtree split --prefix=stampcut -b stampcut-main
```

```bash
git push git@github.com:aostroukhov/stampcut.git stampcut-main:main
```

После этого папку `stampcut/` из `charPicker` можно удалить.
