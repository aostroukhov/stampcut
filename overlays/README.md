# Оверлеи редакции

Сюда кладутся PNG-файлы с альфа-каналом (логотип, плашка, подпись канала).

Рекомендации к файлам:

- PNG-24/32 с прозрачностью, без фона;
- ширина не меньше 1000 px, чтобы оверлей не «мылился» при 25–30 % ширины кадра 1080p;
- без лишних прозрачных полей по краям: позиционирование считается по границе файла;
- имя файла латиницей, без пробелов (`logo-white.png`, `plashka-news.png`).

Файлы из этой папки в git не коммитятся (см. `../.gitignore`). В приложении путь к общей
библиотеке оверлеев задаётся в настройках и может указывать на сетевую или облачную папку.
