# Оверлеи редакции

PNG с альфа-каналом. Эти файлы входят в комплект программы (папка `overlays` рядом с `StampCut.exe`)
и показываются в списке «Файл» панели оверлея. Свои оверлеи кладите в `%APPDATA%\StampCut\overlays`
или в общую библиотеку редакции («Настройки» → «Общая библиотека»).

| Файл | Что |
|---|---|
| `Автогруппа-белый.png` | Логотип автогруппы, белый — для тёмного фона |
| `Автогруппа-черный.png` | Логотип автогруппы, чёрный — для светлого фона |
| `ОИНФО-shadow.png` | Логотип «ОИНФО» с тенью |
| `oinfo.ru-shadow.png` | Подпись `oinfo.ru` с тенью |
| `max.ru-oinfo_news-shadow.png` | Подпись `max.ru/oinfo_news` с тенью |
| `t.me-oinfo_news-shadow.png` | Подпись `t.me/oinfo_news` с тенью |
| `t.me-oinfo_chat-shadow.png` | Подпись `t.me/oinfo_chat` с тенью |
| `t.me-odiauto-shadow.png` | Подпись `t.me/odiauto` с тенью |
| `t.me-odinmam-shadow.png` | Подпись `t.me/odinmam` с тенью |
| `t.me-odintsovoBot-shadow.png` | Подпись `t.me/odintsovoBot` с тенью |

Рекомендации к файлам: PNG-24/32 без фона, ширина не меньше 1000 px, без лишних прозрачных полей по краям,
имя без пробелов.
