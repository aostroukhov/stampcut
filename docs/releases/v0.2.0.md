## StampCut 0.2.0 — интерфейс Windows 11, фрагменты, проект, фильтры

### Внешний вид
- Тема Fluent (как в Windows 11): системные элементы, скругления, подложка. **Тёмная тема** по настройке Windows или вручную («Настройки» → «Тема»).
- Иконка приложения. **Русский и английский** интерфейс («Настройки» → «Язык», применяется после перезапуска).
- Приложение собрано на .NET 10.

### Монтаж
- **Несколько фрагментов в одном ролике**: «+ Фрагмент» на панели управления или в контекстном меню ленты; у каждого свои вход и выход, все уходят в экспорт по порядку.
- **Контекстное меню ленты** (правая кнопка): вход/выход здесь, новый фрагмент, удалить, выровнять вход, выход или все фрагменты по ближайшему ключевому кадру, перейти к предыдущему или следующему ключевому кадру, показать ключевые кадры.
- **Режим «По склейке»** (включён по умолчанию): воспроизведение идёт только по фрагментам и переходит к следующему ролику — ровно то, что будет на экспорте.
- Управление как в плеерах: ←/→ 5 с, Shift — 1 с, Ctrl — 30 с, `,` и `.` — кадр, ↑/↓ — громкость, `M` — без звука, Ctrl+S — сохранить проект.
- Значки кнопок транспорта различаются: кадр назад/вперёд — ◁ ▷, воспроизведение — ▶.

### Оверлей, ретушь, звук, цвет
- Оверлей: без сетки и чисел — только перетаскивание по кадру и изменение размера за любую сторону или угол.
- Мозаика: явный **размер квадратика** в пикселях; размытие: **радиус**. 0 — авто.
- **Громкость ролика** — один ползунок: так ролик играет в программе и с таким уровнем (дБ) уходит в экспорт. Сохраняется в проекте.
- **Фильтры видео** на ролик: тени, светлые участки, насыщенность, яркость, контраст; результат виден на паузе (кадр считает ffmpeg), «Ко всем роликам».

### Проект
- **Сохранить/открыть проект** (`.stampcut.json`): ролики с фрагментами, кропом, ретушью, запикиванием, громкостью и фильтрами, оверлеи, пресет экспорта. Файл проекта можно открыть двойным кликом или перетащить в окно; переехавшие видео ищутся рядом с проектом.
