## StampCut 0.4.0 — переходы, стабилизация, текстовые плашки, поиск лиц, новая компоновка

- **Переходы между фрагментами**: в панели «Экспорт» — вид (затемнение, растворение, через чёрное/белое, шторки, сдвиги, круг, пиксели) и длительность. Звук сводится кроссфейдом. Каждый переход укорачивает результат на свою длительность; переход не длиннее половины самого короткого фрагмента. В ffmpeg — `xfade` + `acrossfade`.
- **Стабилизация**: ползунок «Стабилизация» (0…10) в панели «Видео» для каждого ролика. Работает при экспорте в два прохода (`vidstabdetect` → `vidstabtransform`), прогресс учитывает анализ. На превью не показывается.
- **Текстовые плашки**: кнопка «+ Текст» в панели «Оверлей» — заголовок, подпись, источник. Шрифт, размер в процентах высоты кадра, жирность, цвет, подложка, обводка, выравнивание строк; перенос по словам. Перетаскивание и растягивание на превью как у PNG-оверлея, растягивание меняет размер шрифта (текст остаётся чётким). Сохраняется в проекте и в пресетах оверлея.
- **Поиск лиц** встроенным детектором Windows (Windows.Media.FaceAnalysis, без облака): в панели «Ретушь» — «Найти в кадре» (неподвижные области) и «Найти по ролику» (проход по активному фрагменту с шагом 0,5 с, лица связываются в дорожки, области получают движение по точкам и интервал показа). Найденное — обычные области размытия, их можно поправить или удалить.
- **Бип на уровне дорожки**: громкость тона 1 кГц ставится по замеру RMS звука ролика в самом интервале «пика» (с учётом поправки громкости ролика) — не громче и не тише речи. Замер делается в фоне при создании/изменении интервала и перед экспортом; в превью тон звучит на том же уровне. Исправлено: галочка «Выровнять громкость» не доходила до экспорта.
- **Новая компоновка панелей** по образцу больших редакторов: слева «Медиа» (кнопки «Открыть…», «+ Добавить», «Недавние» прямо в панели) и единая панель «Экспорт» (пресет, громкость, переходы, кнопка, прогресс, готовые файлы); справа — инспектор свойств ролика; в шапке — только «Проект», «Настройки», «?». Уведомления показываются полосой над строкой состояния, а не поверх видео.
- **Контекстное меню** по правой кнопке у роликов в «Медиа» и у готовых файлов в «Экспорте»: открыть, показать в папке, скопировать путь, удалить.
- CLI: `--transition SEC[:вид]`, `--stabilize 1..10`, `--normalize`; уровень бипа замеряется автоматически.
- Приложение собирается под Windows SDK 10.0.19041 (нужно для детектора лиц); минимальная ОС — Windows 10 2004.
