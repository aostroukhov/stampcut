## StampCut 0.2.2 — экспорт через NVENC, окна настроек

- **Экспорт через NVENC не запускался** («CreateInputBuffer failed») в связке с аппаратным декодированием D3D11VA: в этом режиме кодер получает устройство DirectX и принимает только NV12. Для аппаратных кодеров (NVENC, Quick Sync, AMF, Media Foundation) цепочка фильтров теперь заканчивается NV12, для libx264 — по-прежнему YUV420P.
- Проверка GPU при запуске тестирует кодер в той же связке, что идёт в экспорт (аппаратное декодирование → фильтры → NV12 → кодер); если связка не работает, этот кодер используется с программным декодированием. Кэш проверки пересчитывается автоматически.
- **Окна настроек и ввода были чёрными с невидимым текстом**: у окон фиксированного размера не работает подложка Mica. Им задан сплошной фон темы.
- Полоса уведомления переносит кнопки на новую строку, если текст длинный.
