## StampCut 0.1.0 — первая версия (Этап 1, MVP)

Быстрый видеоредактор и плеер для редакции: обрезка, склейка, оверлей, кроп, ретушь, запикивание и экспорт MP4 для Telegram в один клик.

### Что внутри

- **Плеер**: двойной клик по видео или «Открыть с помощью» → файл сразу играет. HEVC/HDR с iPhone, повёрнутые и не-MP4 файлы получают прокси для просмотра автоматически.
- **Обрезка** (`I` / `O`), **склейка** нескольких роликов по порядку.
- **Оверлей** PNG (до трёх): перетаскивание на превью, 9 якорей, прозрачность, интервал показа, плавное появление, пресеты и общая библиотека редакции.
- **Кроп** с пропорциями 9:16, 1:1, 4:5, 16:9 и свободно; «применить ко всем».
- **Ретушь**: размытие или мозаика на лица, номера, недопустимый контент.
- **Запикать**: фрагмент звука тоном или тишиной.
- **Экспорт**: авто-качество (CRF 18 + потолок битрейта по исходнику), размер и частота исходника без увеличения, H.264 High + AAC, `faststart`, уровень H.264 по размеру кадра — формат, который Telegram и соцсети играют без пережатия.
- **GPU**: NVENC / Intel Quick Sync / AMD AMF и аппаратное декодирование, автоматически с откатом на CPU.
- **Без перекодирования**: обрезка и склейка совместимых файлов за секунды.
- Недавние файлы и папки, автоматические имена, горячие клавиши, `stampcut.exe` для командной строки.

### Файлы

- `StampCut-Setup-0.1.0.0.exe` — установщик (ярлыки, «Открыть с помощью», по желанию — программа по умолчанию для видео).
- `StampCut-portable-win-x64.zip` — распаковать и запустить `StampCut.exe`.

FFmpeg уже внутри. Установщик не подписан: SmartScreen покажет предупреждение — «Подробнее» → «Выполнить в любом случае».

### Важно

Это первая сборка: ядро проверено на реальном ffmpeg и покрыто тестами, интерфейс собран автоматически и
**ещё не проходил ручную проверку на Windows**. О любых проблемах пишите в Issues: приложите файл журнала
(«Настройки» → «Открыть папку журналов») и, если экспорт не удался, команду ffmpeg из кнопки «Скопировать команду ffmpeg».

Чтобы Telegram не пережимал видео, отправляйте с Telegram Desktop или «как файл».
