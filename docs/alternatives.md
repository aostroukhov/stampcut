# Готовые и open-source решения: что взять за основу

Дата обзора: 2026-11-03. Вопрос: есть ли готовый продукт, закрывающий задачу редакции
(быстрая обрезка + PNG-оверлей с положением/размером/прозрачностью + MP4 для Telegram)
или open-source проект, который дешевле доработать, чем писать своё.

## Короткий ответ

1. **Попробовать без разработки:** Clipchamp — он уже встроен в Windows 11, умеет PNG-оверлей,
   прозрачность, экспорт 1080p бесплатно. Если редакция готова терпеть его неторопливость и
   аккаунт Microsoft — задача закрыта за 0 рублей. Неделя тестовой эксплуатации (Этап 0 ТЗ).
2. **Уже сегодня, без GUI:** `scripts/stampcut.ps1` — PowerShell-обёртка над FFmpeg, делает
   обрезку + оверлей + нормализацию одной командой с теми же параметрами, что в ТЗ.
3. **За основу для доработки** реально подходит только **LosslessCut** (и то с оговорками),
   остальные либо слишком большие (Shotcut, OpenShot, Kdenlive), либо слишком старые
   (Avidemux), либо не покрывают оверлей (VidCutter). Вердикт: **писать своё тонкое
   приложение дешевле, чем выпиливать лишнее из чужого**; у LosslessCut и Avidemux брать
   готовые приёмы работы с FFmpeg, а не код.

## Подробнее о кандидатах для форка

### LosslessCut

- Самый близкий к Machete по философии: однооконный, быстрый, FFmpeg внутри, активно
  развивается (релизы 3.69–3.70 в 2026 году). Лицензия GPL-2.0, скачивать только с GitHub
  или losslesscut.app (есть поддельные «оптимизаторы»).
- Стек Electron + TypeScript + React: для команды с веб-опытом (как у `charPicker`) порог
  входа низкий.
- Что пришлось бы сделать: добавить режим «экспорт с перекодированием» (фильтры overlay,
  масштаб, тонмэппинг), панель оверлея с превью, пресеты. По сути — те же 70 % работы,
  что и в своём приложении, плюс изучение чужой кодовой базы (сотни файлов) и вечный
  конфликт с апстримом при обновлениях.
- Что точно стоит взять: приёмы работы с FFmpeg (разбор прогресса, прокси для
  неподдерживаемых форматов, обрезка по ключевым кадрам, обход особенностей
  контейнеров). Заимствование **кода** возможно только при лицензии GPL у StampCut.

### Avidemux

- Умеет ровно то, что нужно: Copy-режим для обрезки, фильтр «Logo» с позицией и альфой,
  экспорт в MP4. Нативный, относительно небольшой.
- Но: C++/Qt кодовая база двадцатилетней давности, интерфейс далёк от «одна кнопка»,
  пресетов оверлея нет, превью оверлея — через отдельное окно фильтра. Переделка UI
  под редакцию дороже, чем новый тонкий клиент.

### Итог для ТЗ

Своё приложение с FFmpeg под капотом (раздел 9 ТЗ): собственного кода мало (окно,
таймлайн, панель оверлея, генератор команды ffmpeg), вся тяжёлая работа — в FFmpeg,
который и так лежит под всеми перечисленными проектами. Это даёт «маленькое и быстрое»
приложение в духе Machete и не тянет за собой чужой интерфейс.
