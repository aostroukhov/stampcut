# Пресеты

Формат файлов, который будет читать приложение. Пользовательские пресеты лежат в
`%APPDATA%\StampCut\presets\` или в общей папке редакции (настраивается).

- `export/` — пресеты экспорта: кодек, размер кадра, способ вписывания, частота кадров, звук.
- `overlay/` — пресеты оверлеев: файл, якорь, отступы, размер, прозрачность, интервал показа.

Поля описаны в `docs/TZ.md`, раздел «Модель данных».
